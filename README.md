## Featured projects

**[Grid Signals](https://github.com/kaarelkivisalu/grid-signals)** — Nordic-Baltic energy intelligence platform.
ETL pipelines pulling day-ahead prices, generation mix, load and weather (ENTSO-E, Open-Meteo) into DuckDB, forecasting, a Streamlit/Plotly dashboard, and a Claude-powered agent that answers market questions and writes daily briefings.

**[Estonian Olympiads Database](https://github.com/kaarelkivisalu/eoa)** — [eoa.ee](https://eoa.ee)
A public database and ETL pipeline covering 30 years of Estonian olympiad results. Co-built and maintained since 2020, leading a team of 4 volunteer developers.

**[FEM Helmholtz Solver](https://github.com/kaarelkivisalu/fem-1d-cpp)** — from-scratch finite element solver in C++.
Shape functions, quadrature, and residual/Jacobian assembly for the 1D Helmholtz equation, written for my Manchester MMath&Phys project.

**HEP data compression** (Master's thesis) — autoencoder-based compression of CMS LHC jet data (up to 7.7M events) on GPU clusters, built on top of the open-source [Baler](https://github.com/kaarelkivisalu/baler) tool. Tracked down a normalisation bug that had been blocking real-time compression, and built an outlier-handling method for error-bounded compression of rare events.
